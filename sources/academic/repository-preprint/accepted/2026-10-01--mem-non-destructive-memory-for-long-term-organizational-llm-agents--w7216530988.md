# Mem++: Non-Destructive Memory for Long-Term Organizational LLM Agents

## Relevance decision

This refresh-window preprint is relevant because it provides primary academic evidence about organization-memory, supersession, evals, benchmark for long-horizon organizational or agent memory systems. It is theory/tooling evidence rather than an organization case study.

## Preserved abstract evidence

Large Language Model agents now take part in organizational work, where many authors record decisions across documents over months. Mem++ stores every document whole with its date and author, retrieves only documents dated up to the time a question asks about, and evaluates on OrgMemBench, where it surpasses memory-system baselines.
