# DolphinBench: Mapping the Pareto Frontier of Agent Memory

## Relevance decision

This refresh-window preprint is relevant because it provides primary academic evidence about agent-memory, evals, task-completion, benchmark for long-horizon organizational or agent memory systems. It is theory/tooling evidence rather than an organization case study.

## Preserved abstract evidence

DolphinBench evaluates memory directly through agent task completion. It includes knowledge-work personas with roughly 500k tokens of user messages and verifies tasks by running an agent with and without relevant history, requiring success with it and failure without it, while reporting cost and latency alongside accuracy.
